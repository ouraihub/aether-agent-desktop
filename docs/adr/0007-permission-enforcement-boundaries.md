# ADR 0007：参考OMP的权限模式与执行边界

- 状态：提议（按用户反馈修订）；用户明确要求参考OMP不反复授权的开发体验，撤回此前仅单次批准的提案。具体接口与实现尚未交付。
- 日期：2026-11-08
- 依据：用户指定参考本机Pi/OMP，并明确“我现在用omp 开发就没有授权”；Aether架构§6、Core详细设计§7、接口契约§11。
- 关系：补充ADR-0004/0005，不替代Runtime协议、进程隔离或OS路径机制决策。

## 实际参考与差异

Pi `packages/coding-agent/src/core/agent-session.ts` 的_beforeToolCall仅在存在扩展处理器时执行；runner.ts中block结果阻止调用。project-trust.ts在无UI且没有信任决定时返回false，但项目资源信任不等于逐工具权限或OS隔离。Pi README明确默认以启动用户权限运行。

OMP `packages/coding-agent/src/tools/approval.ts`支持allow/deny/prompt及always-ask、always-ask-cached、write、yolo模式。配置默认可为yolo，正常调用通常直接执行，不要求用户逐次授权；工具或用户deny仍生效，restrictedFolders可将非deny结果改为逐次prompt。缺失上下文时的always-ask不能当作实际会话的默认体验。未读取用户当前实例配置，不断言其具体生效项。wrapper.ts对扩展修改后的实际参数重查；只有确实需要审批时，无交互通道或非明确批准才拒绝。工具审批不是OS沙箱。

## 修订方向与采用边界

1. 优先复用OMP的模式化体验，不把每次工具执行都变成人工审批，不要求用户反复确认已有参考实现能回答的设计细节。用户本轮反馈不是对任意危险命令的概括授权，也不自动批准依赖或沙箱选型。
2. 保留可配置的直接执行、按操作等级确认和缓存确认路径。OMP默认yolo的事实不自动覆盖Aether现有最小权限、Workspace、进程环境及危险操作策略要求；在正式契约中落实配置如何满足这些要求，不能靠增加弹窗代替设计。
3. 不再将批准强制限定为一次。确需交互时参考OMP的单次、会话内工具批准、目标/目录的会话或跨会话记忆；只展示当前调用确实支持的选项，不凭空扩大授权范围。
4. OMP缓存按能力等级和目标匹配；目录授权只覆盖自身直接条目，不自动覆盖子树；多目标调用须全部被覆盖。会话工具批准绑定工具/子工具及等级，不把写批准当执行批准。显式逐次确认及restrictedFolders不被普通缓存跳过。
5. 执行前按实际参数、当前策略和有效授权范围重查。一次批准不能误用于别的请求；会话/持久批准不应因每个新request都弹窗。会话结束清除会话授权，持久记忆仅来自明确选择，并支持清除；具体存储依赖仍由DEC-08收敛。
6. Runtime原生审批只映射真实协议支持；不为了统一界面给本来可直接执行的Runtime逐工具再加一层Aether弹窗。Aether自己执行的工具仍遵守Host执行门。没有OS沙箱不等于一律禁止使用Runtime；只有工作流明确要求的强制限制无法兑现时，才不能冒充满足该限制。
7. 当前Platform路径对象只是UTF-8值。路径授权仍需考虑链接/重解析点和检查到使用竞态；受管进程环境白名单、借用连接不能擅自终止外部进程、日志不泄漏凭据等既有要求保留。不得将工具审批或免审批描述成OS隔离。

## 威胁/验收矩阵

| 场景 | 提案要求 |
| --- | --- |
| 显式工具deny与直接执行模式同时存在 | deny不被模式或缓存绕过 |
| 直接执行模式下普通调用 | 无需审批事件即可按策略执行，不人为再加弹窗 |
| 单次批准误投另一请求/目标 | 拒绝误用，不扩大批准范围 |
| 会话授权内的后续同工具同等级调用 | 不重复弹窗；显式逐次确认规则仍生效 |
| 目录批准后访问子目录或提升等级 | 不将原批准扩成子树或更高能力 |
| 多目标调用只有部分目标获批 | 未覆盖部分不能借用已有缓存 |
| 需要Ask但无人回答或请求已取消 | 不伪造批准；不影响本来无需Ask的调用 |
| 会话结束或用户清除记忆 | 对应授权失效，不能继续命中旧缓存 |
| Runtime未提供OS隔离 | 准确展示边界，不默认加逐工具审批或虚称沙箱 |

## 完成条件与当前缺口

此前“只允许单次批准”和新增的未隔离模式二选一不再作为当前方案，不继续向用户重复发问。DEC-07按OMP方向继续收敛正式合同与Aether作用域映射；尚未完成接口/存储/真实执行验证，不能将本修订当作权限功能完成。Core详细设计§7及APP-05验收方向已同步，单次批准只是可选范围之一。
